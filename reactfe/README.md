# Movie App

A movie discovery app built with **React**, **Vite**, and the **TMDB API**.

## Features

* Browse popular movies
* Search movies
* Add/remove favorites
* Persistent favorites using localStorage

## Tech Stack

React • Vite • React Router • Context API • TMDB API • CSS

## Setup

```bash
npm install
npm run dev
```

Create a `.env` file:

```env
VITE_TMDB_API_KEY=your_api_key_here
```
